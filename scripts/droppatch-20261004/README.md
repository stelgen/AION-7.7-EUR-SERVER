**Параметры (в `patch_drop.py`):** `K=200` (множитель шмота/зелени), `FLOOR=5 000 000` (записи ≥50% не трогаем), `MAXP=10 000 000` (кламп 100%), `CASH_MULT=10`.

**Механика NC-PTS (подтверждена):** RNG 1..10 000 000; prob=10M = 100% гарантированно.
