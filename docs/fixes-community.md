Тред: [AION7.7pts (Europe) set up tutorial](https://forum.ragezone.com/threads/aion7-7pts-europe-set-up-tutorial-and-server-download-address.1211744/)

⚠️ Файлы-аттачи из треда (Server64.7z, SQL-скрипты) могут требовать аккаунта/реакций на RaGEZONE — здесь только **ссылки на посты** + описания методов. Скачивать самим.

## 🥇 Server64.exe патченный (date check bypass) — пост #180

**Автор**: Angry Catster (окт 2024).
**Что чинит**: `invalid system time` при запуске Server64.exe в 2024/2026 (тот же баг, который мы чиним через RunAsDate).
**Аттачи**:
- `Server64.7z` (4.8 МБ) — **exe с патченной проверкой даты** (hex-патч).
- `aion 7.7 fix manastones saving.txt` (607 байт) — SQL-скрипт: фикс сейва манастоунов после релога. ⚠️ Автор честно говорит: Одия/руны всё равно ресетнутся.

**Как юзать**: скачать с поста [2], распаковать, заменить `D:\AION_LIVE_SERVER\MainServer\Server64.exe` на патченный. После этого RunAsDate можно не юзать. Перед заменой — бэкап оригинала.

## 🥈 CacheD64 фикс — пост #174

**Автор**: Jagger1998 (сент 2024).
**Что чинит**: CacheD64 не может коннектиться к БД (окно SQL Login не принимает ввод).

**Метод**:
1. Удалить БД `BkPetitionDB` целиком.
2. Запустить CacheD64.
3. В окне выбрать базу **`aionworld_110`** (не `aionworld_new`!), логин **`Wutian520`**, пароль **`Wutian520`**. (⚠️ это метод автора поста с его заводским паролем; у нас пароль sa сменён на `123` — см. README «Диалоги».)

⚠️ **У нас работало и с `aionworld_new.dsn` + sa/123** (после `max text repl size=65664`) — наш метод может быть проще. Этот метод — альтернатива, если после max-text-repl всё равно не взлетит.

## 🥉 Обновлённая сборка-фикс — пост #168

**Автор**: Jagger1998 (сент 2024), пасс `pG2P`.
«new version repair» — обновлённая сборка с пачкой исправлений (фиксы классов, питомцев). В треде есть Google Drive зеркала в постах #171-172 (klasix) [2].

⚠️ Сборка тянет ~40 ГБ RAM по умолчанию (klasix в #169) [2]; Mantios в #170 предлагает патчи через IDA Pro для снижения до ~20 ГБ [2].

## 📊 БД 5.8 PTS ближе к 7.7 — пост #201

**Автор**: a7741200 (июль 2025): «5.8 databases are closer to 7.7 databases» [4].
Если не хватает процедур в 7.7-комплектной БД — можно попробовать подтянуть недостающее из БД **5.8 PTS** (если где-то найдёшь; в треде её выкладывали в постах 2023 года).

## 🚫 Известные баги сборки (неправятся без IDA Pro)

- **Коллекции**: после lvl 78 открываются, но не работают, нет рецептов крафта [2].
- **Дроп в Heiron (LF3)**: мобы 10-20 lvl не дропают ничего [3].
- **БД incomplete ~85%** — главный корень всех багов [2].
