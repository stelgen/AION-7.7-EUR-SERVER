# XP-айтемы (мгновенный опыт) — механика и выдача

Дата: 05.10.2026. Всё проверено на живом проде (VM 109, Server64 #180 + NPCSvr 7.7).

## TL;DR

- Опыт айтемами живёт в `item_etc.xml` в поле `<bonus_addexp_item>` (180 записей, других item-файлов не касается; `items.xml` — merged-дубль).
- Формат значения: `exp N` — фиксированный XP; `exp N%` — **мгновенная выдача N% полоски текущего уровня** (НЕ баф).
  Доказательство — KR-desc в `Map\XML\Russia\Strings.xml`: «1%의 경험치가 즉시 획득» = «1% опыта мгновенно».
- Сервер проверяет БД-правки на подхват: грант кины 500M (`UPDATE user_item ... name_id=182400001`) подхватился клиентом без рестартов; INSERT монеты — аналогично (перезаход в мир).

## Шпаргалка INSERT (user_item)

- `slot` = тип контейнера (0 = куб, 1 = экип); позиция в кубе = `slot_id` (кина имеет slot_id=-1, спец-склад = warehouse 10/11/12).
- `producer` NOT NULL — писать пустую строку `''` (NULL валит INSERT).
- `server_of_origin=1`; `tid/expired_time/buy_amount/buy_duration/main_item_dbid/dynamic_property/import_id/export_id` = 0; `id` — identity.
- Правку видит клиент после перезахода в мир (инвентарь грузится при входе); если чар онлайн в мире — сервер перезапишет своим кэшем при сейве.
