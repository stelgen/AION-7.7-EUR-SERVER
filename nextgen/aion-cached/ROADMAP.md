## R5 СВИТЧ-ТЕСТ #5 — ВЕРДИКТ (28.10, мир восстановлен 8/8 на копии-2016)

**Попытка**: v18 (aion-cached 3d957383, конфиг 2006/2007/2009 по bak-r5b-канону) + ПОЛНЫЙ стек поднят перед тестом (MSSQLSERVER/accache/logd/IC/PA были мёртвы с 24.10; дубли вычищены: LogServer64-ориг PID 7968, ICServer-дубль PID 3200; пара перезапущена restart_pair).
**Результат = FAIL по критерию** («NPC Server Started» + 8/8):
- Server64 + NPCSvr подключились к НАШЕМУ 2006 (ESTABLISHED подтверждено netstat);
- NPCSvr прошёл ПОЛНЫЙ World::Load (LF4/LF3, warnings spawn-точек = норма) + IOThread/NetworkThread init, RAM-кривая 14.9ГБ пик → 876МБ стабильно — **Started НЕ напечатан за 15+ мин**;
- Server64 висел в autoShutdown-зависании (RAM 366МБ, 2002/7777 не слушали, conns 0; спам 0xC000020D/Close — уже известный фон);
- cached-stdout.log тишина после баннеров: v18 = событийный лог (VERSION/поллы 282/tl_-строки молча) — **raw-картины кадров нет** → вердикт по кодам невозможен без raw-лога/тапа.
**Новые факты (сужение гипотез)**:
- (б) уточнена: NPCSvr НЕ падает до сетевой фазы — он **ЗАВИСАЕТ ПОСЛЕ** IOThread-init, вероятно на неотвеченных GP-цепочках батча C204/110/346/253/326 → {147×3,238,36,222,37} (маппинг ⏳);
- Server64-зависание = каскад от NPCSvr (Started нет) — отдельной проблемы не видно.
**Откат (канон, ~40 мин до 8/8)**: taskkill нашего (5416) → conf.bak-r5b → тень 2018/2019/2020 (PID 4416) → cd2016 (2016/2017/2009) → cdmirror (2006) → пара вручную по одному (restart_pair был заблокирован в LOADING-окне — обходим stop main/start npc/start main) → **«NPC Server Started» 07:18:26 + conns 8/8 + 7777 LISTENING**; юзер логинится (C224 wardrobe через тень в логе).
**Следующий шаг (R5 #6)**: v19 = raw-лог КАЖДОГО кадра (hex head) в stdout/файл при любом коннекте (иначе вердикт вслепую) → повтор свитч-теста → сверка зависших цепочек NPCSvr с testdata/npcsrv_*.bin → реализация недостающих GP-ответов.

## R5 СВИТЧ-ТЕСТ #6 — ВЕРДИКТ v19 RAW-ЛОГ (28.10, мир восстановлен 8/8)

**v19** (ddc3d0e, exe 9bfe28c4): RAW-лог КАЖДОГО кадра (RAW>/RAW</RAWR> hex) — урок #5 «вердикт вслепую невозможен» закрыт. Деплой: тень пассив (тап-кадры юзера C224 видны) → свитч (bak-r5c-канон: конф 2006/2007/2009) → пара рестарт.
**Результат = FAIL по критерию** (Started/8/8 нет) → откат каноном, мир 8/8 восстановлен.
**RAW-карта теста** (159 кадров, [raw-v19-swtch6-20261028.txt](../cached-ref/logs-hourly/raw-v19-swtch6-20261028.txt)):
- Server64-коннект: C277×97 + C179×54 (тикеры Т28 идут!) + C282×3 (поллы) — **НЕТ C215, НЕТ init-набора C201/C161/C211/C325**; RAW< = 0 (мы молчим по канону);
- **NPCSvr-коннект: 0 байт за весь тест** (TCP ESTABLISHED есть, но даже C201/C134 не послан);
- **NPCSvr висит в SYN_SENT → 127.0.0.1:2002** — live-доказательство второго коннекта NPCSvr→Server64;
- Server64 2002/7777 НЕ слушает весь тест; .err: HookIAT complete 08:16:40 → «Waiting for Cache Version» → фазы AbyssMgr/HousingData/TownChallenge НЕ пришли (в эталоне 24.10 шли сразу после).
**СУЖЕНИЕ БЛОКЕРА (вместо GP-батча C204/110/346/253/326)**: пара стоит в замке «Server64 ждёт Cache Version ⟷ NPCSvr ждёт Server64:2002»:
- Server64 не шлёт init-набор (в эталоне 24.10: коннект 02:41:54 → C201 через ~2 мин → O28 → C161/C211/C215→O16+O123 → C325 → фазы → Started); «Waiting for Cache Version» = ожидание RP_VERSION по 2006;
- NPCSvr не начинает CacheD-диалог, пока не соединится с Server64:2002 (dual-connect);
- т.к. Server64-коннект к ориг в 24.10 получил версию (фазы прошли) — приоритетная гипотеза: **CacheD при accept Server64 должен ПУШИТЬ init-кадр(ы) (кандидат O16 RP_VERSION 27Б / O196-ack), которого наш v19 не делает** (RAW< = 0).
**Следующий шаг (R5 #7, оффлайн → v20)**: разложить capture-окна (worldinit-20261023.txt + cdmirror-20261024-worldstart.log) по коннектам (фингерпринты C282=Server64-полл, C201=NPCSvr-handshake) → найти ПЕРВЫЙ O-кадр Server64-коннекта = пуш-канон → v20: пуш при accept Server64 (и проверить NPCSvr-accept-пуш C201→O28 уже есть в NpcSrvReplay) → свитч-тест повтор.
