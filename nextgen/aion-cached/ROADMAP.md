## R5 #5 — план (актуализирован 24.10 по свежему мир-init capture)

**Факт-база 24.10** (`cached-ref/logs-hourly/cdmirror-20261024-worldstart.log`, полный рестарт пары через ориг 02:43–03:12 VM):
- **Гипотеза (а) СНЯТА**: C282-полл (0x11A, 11Б) — Server64 шлёт его каждые ~5 мин и при живом ориг тоже; 181 полл за 2 дня — **ориг молчит на 282 всегда**. Наша тишина = корректное поведение, не блокер.
- **RP_VERSION в мир-init = 27Б** (`9c0f0300 7c000000 d8000000 00008000 00000000`) — НЕ логин-форма 850Б. C215(RQ_VERSION) → O16(27Б) + O123(6321Б GP-дамп).
- **НОВОЕ: C36 ×4 (8083Б×3+547Б ≈ 27КБ) — NPCSvr ЗАГРУЖАЕТ данные В CacheD** (silent fire-and-forget) — CacheD не только отдаёт, но и принимает NPC-данные при init.
- Полная NPCSvr-init цепочка снята (см. канон README §Мир-init 24.10); непокрытыми остались только C204/110/346/253/326 → {147×3,238,36,222,37} (маппинг в батче неоднозначный ⏳).
- W30-бёрст (C62→O18×40+5) воспроизвёлся БАЙТ-В-БАЙТ = R4.6.2 канон подтверждён вторым рестартом.
