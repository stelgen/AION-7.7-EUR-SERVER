sgs1011 said:
how to setting exp rate , drop rate ?? help
Click to expand...

For exp you can change that by editing the file: ...\_AION\Server\MainServer\common.xml.
There you will find these lines:

<!-- exp multiple -->
<AbyssPointMultiple>100</AbyssPointMultiple>
<expMultiple>400</expMultiple>
<CraftExpMultiple>200</CraftExpMultiple>

Edit as you wish, save and restart the Main Server

I don't know where is the drop info yet.
