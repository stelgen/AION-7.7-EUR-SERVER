AION 7.7 Server Setup Guide

Prerequisites​

  • SQL 2017 Installation: No need to record this part. You can search for installation guides on Baidu or refer to the AION 4.6 tutorial.
  • Preparation: Start by removing all data from any previous installations.

Server Setup​

Two server programs are available: one for the EU client and one for the Chinese client. This guide uses the EU client setup to make it accessible for international players.

  1. Decompression: Extract the server files to D:\.
  2. Database Installation: The database setup is similar to the AION 4.6 retail server. Although not all databases are required, it's recommended to install them all in case they are needed for future use, such as the GM backend program.
  3. Password Management: If you've forgotten the database sa password, you can change it. The default sa password and the password for aiongm_ur are both Wutian520.
  4. IP Address Setup:
    • Use the command cmd ipconfig to find your server's IP address. In this example, the IP address is 192.168.1.131.
    • If you are using a virtual machine, use the same method to find the VM's IP address.
  5. Configuration: Update the server configuration files with the correct IP address using a text editor.

Starting the Server​

  1. Launch the Server:
    • Click "Run" to start the server.
    • If you encounter any prompts related to 01-10, check aion_accountdb to ensure the account and password are set to sa with the password Wutian520.
    • Also, check L2Conn and other settings to ensure the server starts correctly.

Game Access​

  • The account and password for game access are automatically registered, similar to the AION 4.6 retail server.
  • EU Client Login: Use the EU client to log into the game.
  • Account Creation: If your account disappears, recreate it. For example:
    • Username: a7741200
    • Password: 123456

Final Notes​

The server setup is complete. Explore other features, and fix any bugs you encounter during gameplay.
