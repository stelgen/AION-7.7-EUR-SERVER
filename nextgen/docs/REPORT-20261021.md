### 2. Текущая фаза разработки (W3/R3.6)
**Файл:** `nextgen/aion-accache/internal/server/handlers_r3x.go`
**Логика:** Регистрация 12 недостающих хендлеров для корректной обработки пакетов (0x17, 0x18, 0x1c, 0x1d, 0x1e, 0x20, 0x21, 0x22, 0x23, 0x24, 0x26, 0x27).
**Контроль качества:**
*   **Wire Regression Tests:** Реализованы в `wire_regression_test.go`.
*   **Методика:** Использование `fakeExec` для проверки proc name + args с защитой от off-by-2.
*   **CSV-формат:** `strconv.Itoa` + `strings.Join`.
*   **Datetime:** `time.Unix(...)` для MSSQL.

> [!NOTE]
> **Пульс обновления:** 21.10 — Регистрация обработчиков завершена. Тесты готовы к интеграции в CI. Деградация функции контролируется изоляцией wire-слоя.
