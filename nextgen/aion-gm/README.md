# aion-gm — GM-инструментарий (панель/веб + выдачи) — вероятно НЕ НУЖЕН как отдельный сервис

> ⬜ **Черновик-заготовка, вероятно не понадобится** (решение-кандидат юзера): GM в нашем стеке = `user_data.builder` в SQL + команды `///` из GMcmd.txt; op + SQL-инструменты уже покрывают 90% задач (выдачи/кина/шмот/GM-флаг — отработаны). Страница создаётся для полноты реестра стека и «если захочется веб-бэкенда».
> Запуск: `WORKFLOW: gm`. Стандарты: [../README.md](../README.md) §4.

## 📊 Статус и фазы

| Фаза | Статус |
|---|---|
| R0: инвентарь GM-слоя (что есть: gm.exe = шифровальщик connstr, REF58L_Aion_gm = эталон-БД TBL_ADMIN_USER/TBL_BUILDER_COMMAND_* + mail-shoot, GMServer в 7.7-ките НЕТ) | ⬜ |
| R1: решение юзера — нужен ли веб-панель GM (бизнес-выбор: «да» → MVP; «нет» → АРХИВ страницы) | ⬜ |
| R2 (если «го»): Go `nextgen/aion-gm` — web-UI: выдача шмоток/ предметов (метод отработан: user_item INSERT + rollback-скрипты), builder-флаги, GM-команды-шпаргалка | ⬜ |

## 📟 Канон

| Факт | Источник |
|---|---|
| GM-флаг = колонка `user_data.builder` (уровень 1–5); чар OFFLINE при UPDATE (сервер перезапишет кэш) | live (выдача 06.10) |
| `aion_SetBuilderCharacter(@char_id,@lev)` = простой UPDATE; в прод-БД процы нет, но колонка есть | sp_helptext REF58 |
| GM-команды 7.7: полный список `ref-kits/46-services/GMServer/GMcmd.txt` (+commands.xml); ввод «///команда»; панель Shift+F1; ключевые: gm_race 0/1 (⚠ gm_race 1 = наблюдатель-режим: мобы не агрятся!), gm_undying, movespeed, freefly, wishid, teleport… | GMcmd.txt + live |
| gm.exe (в tool\gmdb) = шифровальщик connstring (gm.txt→gm.bin) — НЕ GM-сервер | live-инвентарь |
| REF58L_Aion_gm = полная GM-БД эталона (TBL_ADMIN_USER с ADMIN_LEVEL, TBL_BUILDER_COMMAND_* очередь команд, mail-shoot) — можно восстановить как БД для веб-бэкенда | REF58-кит |
| GM-шмот: боевого god-tier сета НЕТ; wishid выдаёт любой item_id (метод выдач отработан с бекапом/rollback) | память aion_server |
