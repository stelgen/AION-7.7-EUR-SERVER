## Леджер решений

- **Loopback-capture (что думали → чем доказали)**: думали «pktmon пассивно снимет 2002 (опыт aion-main 7777)» → 08.10 тест: `comp list` = единственный VirtIO NIC, loopback-компонентов нет, capture 2002 = 0 пакетов; 7777 у aion-main шёл по LAN-NIC. Внутренние каналы стека (2002/2006/2007/2009/2051) — всё 127.0.0.1; wire ловим только собственным листенером / тест-миром на LAN / штатными логами NC (штатный packet-лог в NPCSvr64 есть: FileLog::AddPacketLog, PacketProfileLogger — флаг ищем).

- «NPCSvr не переписываем никогда» (05.10 PLAN) — ❌ актуализировано 08.10: переписываем ВСЕ бескомпромиссно; мир = деприор, не отмена. До переписи — ориг + aion-binpatch.
- **2009-гипотеза (что думали → чем доказали)**: думали «:2009 = npcDb-канал, клиент NPCSvr64 (аналог L2 npcDbHandlers)» → 08.10 netstat live: CacheD слушает 2009, но NPCSvr64 ходит в CacheD по **2006** (общий пул, коннект 54079), клиентов на 2009 нет; доки исправлены («исправил = удалил»), cached-ref карту каналов скорректировать при следующем касании. ⏳ остаётся вопрос: КТО предназначен для 2009 (в 7.7-ките не используется?).

## Правила мира (не терять)

- Пара NPC+MAIN рестартится только вместе (op restart_pair); окно загрузки 10–15 мин.
- RAM NPC после спавна падает до ~1 ГБ — НЕ паниковать.
- «NPC Server Started» в .err = готовность.
