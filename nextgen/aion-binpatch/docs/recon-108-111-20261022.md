## Уроки-инструменты (переиспользуемые)

- **VA→file offset**: через секции PE (`RAW = raddr + (VA - base - vaddr)`); Server64: .text VA 0x1000 RAW 0x400, .rdata VA 0x110e000 RAW 0x110cc00.
- **Поиск callers в 45МБ exe**: python-скан E8/E9/FF15/lea-rip/ptr-VA (быстрее полного objdump).
- **publics-офсеты**: sec1 → VA = base + 0x1000 + off; sec2 (.rdata) → НЕ base+0x110e000+off напрямую — сверять фактическим поиском строки (офсеты PDB ≠ RVA-дельта 1:1 для лент).
- **ssh+PowerShell-инлайн = кавычки ломаются** → только scp+File (правило старое, подтверждено дважды за сессию).
- **`/end AionOp` убивает Agent API** (op = API-сервер) → рестарт op только через SSH-канал.
- **aionput ARG_MAX**: 18.5МБ base64 в аргументе curl падает → payload через `--data-binary @file`.
