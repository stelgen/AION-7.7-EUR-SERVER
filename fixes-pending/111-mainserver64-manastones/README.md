# #111 — Mainserver64 «Fix Manastones, Stats, Arenas, Server time» (Ghidra-референс)

**Статус: РЕФЕРЕНС. В прод НЕ деплоить (чужой бинарь, сломан матчмейкер).**

## Цель
Перенести в НАШ чистый Server64 (== #180, SHA256 b000c6f5…) только манастоун-фикс
(бесконечный стекинг статов от манастоунов) методом бинарного диффа.

## План (оффлайн, нулевой риск для прода)
1. Инструменты: Ghidra + `Server64.pdb` из кита (у обоих бинарей есть PDB!).
2. Открыть оба: `tools/ragezone-1211744/111-Mainserver64.rar` (извлечённый Server64.exe) и наш `D:\AION_LIVE_SERVER\MainServer\Server64.exe`.
3. Точка входа для поиска: функции работы с `aion_SetItemMatterOption` / `user_item_option`
   (строки "stat_enchant_name0..5" в .rdata → xref) и код маны-стонов (`manastone` строки).
4. Диффить только базовые блоки вокруг этих функций (FunctionID по PDB-символам).
5. Собрать патч: экспорт изменённых байтов (Ghidra → Export Program → bytes), применить к копии нашего exe офсетом.
6. Тест: КОПИЯ `MainServer_backup_20261002_212213` (или новая папка), RunAsDate → RUN, клиентом
   надеть манастоун → проверить, что стат не стекается бесконечно и сохраняется после релога.

## Откат
Прод не трогаем до полного прогона в копии; в прод — только подменой exe с бэкапом `Server64.exe.etalon-b000c6f5`.

## Артефакт
`111-Mainserver64.rar` в tools/ragezone-1211744/ (+ внутри Server64.exe с фиксами и aion-main-10.reg).
