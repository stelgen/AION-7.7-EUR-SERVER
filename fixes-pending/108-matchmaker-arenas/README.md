# #108 — Матчмейкер (арены) на одном MainServer (AKllX)

**Статус: ПЛАН. Отложено до первого успешного клиентского теста.**

## Суть (RaGEZONE #108, AKllX)
- Main64 умеет быть Matchmaking-сервером: конфиг `IsEventServer=true`.
- Проблема: NCsoft запрещает прямой логин на matchmaker-сервер.
- Фикс: в бинаре изменить условный переход логики IsEventServer для МАТЧМЕЙКЕРА
  JZ → JNZ (или наоборот), НЕ трогая логику логина — иначе не пустит на сервер вообще.

## План
1. Ghidra + `Server64.pdb` → найти строки/символы `IsEventServer` (строка в .rdata → xref).
2. Тестовая копия: `MainServer_backup_20261002_212213` → править КОПИЮ exe.
3. Проверка: клиент заходит на мир (логин не сломан) + арена-заявка уходит (лог MainServer:
   matchmaking-запросы обрабатываются, а не отваливаются).
4. Риск-митигейт: патч изолирован от манастоун-фикса (#111); не совмещать в один бинарь, пока оба не проверены по отдельности.
